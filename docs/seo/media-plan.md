# 「愛犬のお悩み相談室」メディア設計

方針転換（2026-07-20）：これまでは「Woofullの商品に紐づくキーワードだけ」を対象にしていたが、それだと扱える悩みの幅が13商品分に限定され、SEO流入の伸びしろが小さい。
今後は **商品の有無に関係なく、犬の飼い主が実際に検索するであろう悩み** を先に網羅し、`/guides`を独立したコンテンツメディアとして育てる。商品は「記事に合うものがあれば紹介する」程度の位置づけに後退させ、無ければ紹介しない（存在しない商品を無理にねじ込まない）。

まず流入を伸ばし、伸びた後で「読者のニーズがあるのに商品がない」ジャンルへ商品を追加していく（コンテンツ→商品の順）。

## 1. `strategy.md` / `workflow.md`との関係

- ロングテール優先の考え方（Tier1→2→3）、AIっぽさを削るワークフロー（①〜⑦）はそのまま適用する
- 変更点：**キーワードの主対象商品は必須ではなくなる**。`keyword-list.md`の「主対象商品」列は「なし」でよい
- 関連商品が無い記事は、`relatedProductSlugs`を空配列にする（無理に関連付けない。ワークフロー③の「無い機能を書かない」と同じ精神で「無い商品を紹介しない」）
- 内部リンクの主役は「関連商品」から「関連記事（同じ・隣接するクラスターの記事）」に変わる

## 2. コンテンツの柱（ピラー）とクラスター設計

犬の飼い主の悩みを7つの柱に分類する。各柱に「ピラー記事（広く浅く、将来のTier3キーワード）」を1本、その下に「クラスター記事（具体的な悩み、Tier1ロングテール）」を複数ぶら下げる、ピラー・クラスター構造にする。クラスター記事同士、クラスター→ピラーへ内部リンクを貼ることで、トピックとしての専門性をGoogleに伝える。

| 柱 | ピラー記事（例） | クラスター記事の例（すべてTier1まで具体化してから執筆） |
|---|---|---|
| ① しつけ・問題行動 | 犬のしつけの基本まとめ | 無駄吠え 原因 対策／トイレ 失敗 やり直し／噛み癖 子犬 いつまで／分離不安 サイン 見分け方 |
| ② 健康・体調管理 | 犬の体調不良サインまとめ | 下痢 元気ある 様子見／涙やけ 原因 拭き方／口臭 きつい 病気／シニア犬 痩せてきた |
| ③ 食事・栄養 | 犬のごはん選びまとめ | ドッグフード 切り替え 期間／アレルギー 症状 見分け方／手作りご飯 塩分 量／おやつ 与えすぎ 基準 |
| ④ お手入れ・グルーミング | 犬のお手入れ基本まとめ | シャンプー 頻度 目安／爪切り 血管 出血／耳掃除 頻度 やり方／換毛期 いつ 対策 |
| ⑤ お散歩・お出かけ | 犬の散歩の基本まとめ | （既存クラスターと統合：抱っこ疲れる／アスファルト火傷／うんち袋ホルダー） |
| ⑥ 迎え入れ・初心者 | 子犬を迎える準備まとめ | 子犬 迎える前 準備リスト／初日 鳴き止まない／ワクチン 費用 スケジュール |
| ⑦ ライフイベント・多頭飼い | 犬との暮らしの変化まとめ | 多頭飼い 相性 見極め方／引っ越し 犬 ストレス／赤ちゃん 犬 同居 準備 |

商品と結びつくのは主に③⑤（一部④）。①②⑥⑦は基本的に商品と無関係な「悩み解決コンテンツ」として書く。

## 3. Article型の拡張

`src/lib/articles.ts`の`Article`型に以下を追加する。

- `category`: 上記7柱のいずれか（サイト内フィルタ・パンくず用）
- `pillarSlug`: この記事が属するピラー記事のslug（無ければ自分自身がピラー）
- `relatedArticleSlugs`: 関連記事（同じ柱・隣接する柱）へのslug配列。**新方針での内部リンクの主役**
- `relatedProductSlugs`: **空配列を許可**（商品が無ければ空でよい）

## 4. `/guides`の構成変更

- トップに柱（カテゴリ）ごとのセクション、またはフィルタタブを設置し、記事が増えても迷子にならないようにする
- 各記事下部：「関連商品」（あれば）に加えて「関連記事」ブロックを新設し、同じ柱の記事へ回遊させる
- ピラー記事は将来的に`/guides/category/[category]`のような一覧ページに発展させる余地を残す（今回は`pillarSlug`でデータだけ用意し、ページ構造は次フェーズで検討）

## 5. 品質基準（`strategy.md`の補足）

- 商品が無い記事は、「Woofullの独自の考え方」ではなく、**一般的に信頼できる知識**として書く。獣医療に関わる内容（下痢・嘔吐・皮膚トラブル等）は特に、断定を避け「異変が続く場合は動物病院へ」を必ず添える
- 商品紹介を無理につけない。CTAは「関連記事を読む」「（あれば）商品ページへ」のどちらか自然な方にする
- 引き続き①〜⑦のワークフローを厳守し、**下書きを提示して承認を得てから公開する**（今回のミス）

## 6. 進め方（今回のタスク）

1. 本ドキュメントの柱・クラスター案をYuさんに確認してもらう
2. OKが出た柱から、`keyword-list.md`にTier1キーワードを追加する
3. 1本サンプルを書いて提示 → 合格ラインの確認 → 残りを量産
4. Search Consoleにデータが溜まってきたら（1〜2ヶ月後目安）、実際の流入キーワードを見てクラスターを追加・修正する
