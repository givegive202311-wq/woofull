# SEO戦略ドキュメント（キーワード優先順位・コンテンツ品質基準）

`docs/seo/workflow.md`の「AIっぽさを無くすワークフロー」に対する追加ルール。
既存12記事の品質不足（画像なし・内容が薄い）を受けて、方針を明文化してから実行する。

## 1. なぜビッグキーワードを今は狙わないか

Woofullは開設したばかりのドメインで、被リンクも運営履歴も無い。「犬 熱中症対策」のようなビッグキーワードは、獣医メディア・大手ペットECサイト・老舗ブログが上位を占めており、新規ドメインが数ヶ月で割り込むのは現実的ではない。

一方でロングテールキーワード（3〜5語の複合語、状況や悩みが具体的なもの）は、

- 検索ボリュームは小さい（月間10〜90回程度が目安）が、競合するページがほぼ無い
- 検索意図が明確なぶん、購入意欲が高い訪問者が来やすい
- インデックス〜順位反映までのフィードバックが早く、施策の当たり外れを早期に検証できる

という特徴がある。**開設初期はロングテールキーワードだけを狙い、それらが安定して流入・被リンクを獲得してから、徐々に広いキーワードへ広げる。**

## 2. キーワードの階層（Tier）

| Tier | 特徴 | 時期 | 例 |
|---|---|---|---|
| Tier 1（最優先） | 4語以上、状況・悩み・製品タイプが具体的、競合ほぼ無し | 今すぐ | 「犬 早食い 器 ステンレス 陶器 どっち」 |
| Tier 2 | 3語程度、購入ガイド・比較系。ある程度の競合あり | Tier1が流入し始めてから（3〜6ヶ月後の目安） | 「犬 早食い防止 グッズ 比較」 |
| Tier 3 | 1〜2語のビッグキーワード。強豪サイトが多数 | Tier2が育ってから（半年〜1年以降） | 「犬 熱中症対策」 |

新しいキーワード候補は、まずTier1相当まで具体化してから`keyword-list.md`に追加する。「とりあえずビッグキーワードで書く」をやらない。

## 3. Tier1キーワードの作り方（具体化のパターン）

広い悩みワードに、以下の要素を足して具体化する。

- **状況を足す**：「留守番中」「通院時」「雨の日」「夏場」など
- **比較対象を足す**：「ステンレス vs 陶器」「〇〇と△△どっちがいい」
- **対象を足す**：「小型犬」「シニア犬」「短頭種」など、対象犬種・体格
- **形式を足す**：「選び方」「サイズの測り方」「慣らし方」など、読者が次に取る行動
- **数値を足す**：「体重〇kg」「サイズ表」など、specs記載の実データ

例：「早食い防止」（Tier3・広すぎる）
→「犬 早食い防止 ボウル 高さ 首 負担」（Tier1・stand_foodbowlのスタンド構造という独自要素で具体化）

## 4. コンテンツの品質基準（`workflow.md`④⑥の補足）

過去12記事のレビューで「画像がない」「内容が薄い」という指摘を受けたため、以下を必須にする。

### 画像
- 記事に **最低2枚** の商品画像を使う（メイン画像1枚＋サブ画像 or 別商品の画像1枚）
- 画像は `docs/seo/product-facts.md` に対応する商品の実際のSupabase画像URLを使う。存在しない画像・架空の画像は使わない
- altテキストには商品名だけでなく、記事のテーマが伝わる説明を入れる（例：`alt="スタンド付きの早食い防止フードボウルで食事をする犬"`）

### 文章量・具体性
- 本文（directAnswer・FAQ含まず）は **目安1300〜1900字**。文字数を稼ぐための水増しはせず、具体的な内容で自然にこの分量になることを優先する
- 「一般的にはこうです」で終わらせず、`product-facts.md`に書かれている実寸・重量目安・対象犬種などの具体的な数値を最低3箇所は本文に引用する
- 見出し（H2）は5〜7個を目安にし、1見出しあたり最低150字は書く（骨組みだけの見出しを作らない）
- FAQは4〜6問に増やす（ロングテールの疑問形キーワードをFAQの質問文にそのまま使えるようにする）

### 見直しのチェック（⑥に追加）
- [ ] 画像が最低2枚、実在する商品画像を参照しているか
- [ ] 文字数が1300字を下回っていないか
- [ ] 見出しの中身が薄い（1〜2文で終わっている）箇所がないか
- [ ] タイトル・想定キーワードがTier1（具体的）になっているか、Tier3の広すぎるワードのままになっていないか

## 5. 運用の流れ

1. `keyword-list.md`のキーワードをTier1相当まで具体化する
2. 該当記事を本ドキュメントの品質基準に沿って画像追加・大幅加筆する
3. 見直しチェックを通過したものから`src/lib/articles.ts`を更新する
4. 全記事を通過させたら、`docs/seo/keyword-list.md`のステータスと本ファイルの進捗を更新する
